# Facebook → Linktree 每月同步

程式從 Facebook 活動貼文抓取文字、連結和課表圖片，產生 Linktree 更新計畫。預設目標為下個月。請先依 `.env.example` 設定 `.env`，執行 `npm install`，並以 `npm run setup` 登入 Facebook 與 Linktree。

## 本機 App

按兩下專案資料夾內的「每月活動同步.app」，即可在瀏覽器開啟控制頁面。先選擇目標年、月（預設下個月），再按「開始整理」，待資料出現後核對及修改，最後按「確認並更新 Linktree」。執行狀態及錯誤會顯示在頁面上。

此 App 是本機啟動器，需要與本專案資料夾、Node.js、已安裝套件及登入資料一起使用，不可單獨移出專案資料夾。第一次使用，或 Facebook／Linktree 登入過期時，仍需在這台電腦執行 `npm run setup` 並手動登入。

本機服務只監聽這台電腦，App 可重複開啟既有服務。關閉瀏覽器頁面不會停止服務；重新開機後再次開啟 App 即可使用。若無法啟動，請查看 `data/dashboard.log`。也可以執行 `npm run dashboard` 啟動。

## Windows

Windows 版請參考 [WINDOWS-使用說明.md](WINDOWS-使用說明.md)。可先雙擊 `Windows-start.cmd`，也可以在 Windows 執行 `Windows-build-app.cmd` 產生 `.exe` 啟動器。Windows 版本需個別安裝 Node.js、程式套件及登入 Facebook／Linktree。

## AI 模型與費用

每次建立新計畫時，程式查詢 Google 的模型清單、退役公告、標準價格和模型能力，從符合命名格式的穩定 Gemini Flash-Lite 文字模型中，挑選支援圖片輸入與結構化輸出的候選項。已到停用日期或距公告最早停用日 30 天以內的模型會排除。無法確認退役狀態或能力的模型不列入；Google 變更文件格式可能造成自動選擇停止，需要更新程式。

程式以假設輸入 10,000、輸出 2,000 tokens 的費用排序，並由便宜到貴做極短存取測試。Google 回覆 404 不可用或 503 暫時繁忙時，會嘗試下一個候選模型；其他錯誤會停止。此測試本身可能消耗少量 API 額度。執行紀錄會顯示選用的模型與費率；實際費用受 token 用量、帳戶方案與免費額度影響。此機制不涵蓋其他模型家族或不符合命名格式的新模型。

無法查詢官方資料或無符合條件的模型時，程式會停止並提示。已保存的未完成計畫會直接續用，只有建立新計畫才重新選擇模型。舊的 `GEMINI_MODEL` 設定不再決定模型。

## 命令列操作

執行 `npm start` 後，程式會開啟本機核對頁面；若沒有自動開啟，請使用終端機顯示的網址。對照原文及圖片，確認課程名稱、網址與 Bio 休館資訊；可直接修改尚未發布的項目。按「確認並更新 Linktree」才會開始寫入。取消則保留計畫。寫入結果與錯誤請查看終端機；中斷時可重新執行，已完成的卡片不會重複寫入。

`npm run plan` 只產生並保存計畫，不發布，也不會自動通知；之後使用 `npm start` 核對及發布。隨附的排程設定使用 plan 模式。不要使用 `auto` 模式略過人工核對，尤其休館資訊需要與圖片核對。

程式以目標年、月、貼文文字、連結和圖片內容偵測變更；來源變更會產生新計畫。若舊計畫已部分發布，來源又發生變更，程式會停止，需先檢查 Linktree 及 `data/backup_posts.json` 中的舊計畫再處理。同步紀錄與瀏覽器登入資料請妥善保管，不要公開或提交。

手動指定月份可在 `.env` 設定 `TARGET_MONTH=1` 和 `TARGET_YEAR=2027`；只指定月份時年份預設為今年。預設跨年時會選用下一年。年份是搜尋目標及版本識別，Facebook 搜尋和圖片辨識目前仍以月份為主，**請在核對時自行確認貼文及課表年份**。

圖片無法選出、日期辨識不明或缺少必要連結時，程式可能在核對頁面之前停止，請查看錯誤訊息，並檢查 Facebook 登入、貼文和圖片。目前不會自動通知，也無法保證 Facebook 或 Linktree 改版後仍能正常操作。
